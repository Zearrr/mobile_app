# แผนภาพโฟลว์การทำงานระบบ FixFlow Thai

## 1. โฟลว์หลัก: รับงานซ่อม → เสร็จสิ้น

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   ลูกค้านำเครื่อง  │───▶│   รับงานซ่อมใหม่  │───▶│   ตรวจสอบเบื้องต้น  │
│   มาแจ้งซ่อม      │    │   (NewJob.tsx)  │    │   (สถานะ: ตรวจเช็ค) │
└─────────────────┘    └─────────────────┘    └─────────────────┘
                                │
                                ▼
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   ออกใบรับซ่อม   │◀───│   ประเมินราคา   │───▶│   เก็บมัดจำ      │
│   (พิมพ์เอกสาร)   │    │   (สินค้า+ค่าแรง) │    │   (ถ้าจำเป็น)    │
└─────────────────┘    └─────────────────┘    └─────────────────┘
                                │
                                ▼
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   อัปเดตสต็อก    │◀───│   ซ่อมเครื่อง    │───▶│   ทดสอบหลังซ่อม  │
│   (ใช้อะไหล่)    │    │   (สถานะ: ซ่อม)  │    │   (สถานะ: ทดสอบ) │
└─────────────────┘    └─────────────────┘    └─────────────────┘
                                │
                                ▼
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   คำนวณยอดรวม   │◀───│   งานเสร็จสิ้น   │───▶│   ลูกค้ามารับ    │
│   (สินค้า+ค่าแรง) │    │   (สถานะ: เสร็จ) │    │   และชำระเงิน    │
└─────────────────┘    └─────────────────┘    └─────────────────┘
                                │
                                ▼
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   ออกใบเสร็จ     │◀───│   ออกใบรับประกัน │◀───│   ส่งมอบเครื่อง  │
│   (พิมพ์เอกสาร)   │    │   (ถ้ามีประกัน)  │    │   (สถานะ: ส่งมอบ) │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

## 5. โครงสร้างข้อมูลและการเชื่อมโยง

### ข้อมูลหลัก (Primary Data)
```
Jobs (งานซ่อม)
├── Customer (ลูกค้า)
├── Device (อุปกรณ์)
├── Symptoms (อาการเสีย)
├── Status (สถานะ: ตรวจเช็ค/ซ่อม/ทดสอบ/เสร็จ/ส่งมอบ)
├── Payment Status (สถานะชำระ)
├── Parts Used (อะไหล่ที่ใช้)
├── Labor Cost (ค่าแรง)
├── Total Cost (ต้นทุนรวม)
├── Selling Price (ราคาขาย)
├── Profit (กำไร)
├── Deposit (มัดจำ)
├── Warranty (ประกัน)
└── Assigned Tech (ช่างรับผิดชอบ)
```

### ข้อมูลสนับสนุน (Supporting Data)
```
Customers (ลูกค้า)
├── Name, Phone, Address
├── History (ประวัติงานซ่อม)
└── Preferences (ความชอบ)

Parts (อะไหล่/สินค้า)
├── Name, Description
├── Stock Quantity
├── Cost Price
├── Selling Price
├── Min Stock Level
└── Used In Jobs

Users (ผู้ใช้)
├── Role (owner/cashier/tech/staff)
├── Permissions
└── Activity Log

Settings (ตั้งค่า)
├── Shop Info
├── Default Profit %
├── Warranty Days
├── Print Templates
└── System Preferences
```
